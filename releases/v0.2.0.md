Windows 原生启动器，现更名为 **wincast**。

- 全新青绿色 W 图标，搜索面板左下角更简洁。
- 支持应用搜索、剪贴板历史、计算器、词典、笔记、窗口管理和 AI 对话。
- 支持毛玻璃背景、深浅色主题及 Windows 系统强调色。
- 升级自动保留旧 Go 版设置；原目录下的笔记和剪贴板数据继续使用。

**安装：**下载 `wincast Setup 0.2.0 amd64.exe`，或解压 ZIP 后运行 `wincast.exe`。按 **Alt+Space** 开始使用。便携版升级请放回原目录，保留 `data` 文件夹。

需要 Windows 11 24H2 或更新版本，x64。词典数据需单独安装。
